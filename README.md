# Vorentice

**AI-Powered Strategic Supply Chain Intelligence Platform**

Vorentice is a **multi-agent AI platform** designed to monitor global intelligence and identify potential risks affecting strategic supply chains, with a focus on India's crude oil dependency.

### Key Features
- Monitors **15+ global intelligence sources** across **8 risk domains**
- Uses **LangGraph + Azure OpenAI** for multi-agent intelligence processing
- Uses **graph algorithms** to model global maritime supply routes
- Operates on a **40+ node maritime graph** covering supply origins, strategic chokepoints, and refineries
- Converts detected disruptions into **validated alternative routing strategies**

### Tech Stack
`Python` `FastAPI` `LangGraph` `Azure OpenAI` `Graph Algorithms`
